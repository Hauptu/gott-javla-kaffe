# Gott Jävla Kaffe

Projekt för en svensk sajt som hjälper besökare att hitta rätt kaffemaskin utifrån behov, budget och preferenser.

## Status
- 24 produkter i katalogen
- 4-stegs finder
- Matchning, jämförelse, beslutskarta och budgetsimulator
- Affiliatefält förberett, men inga affiliate-länkar inlagda ännu
- Prisdata som inte är verifierad visas inte som verifierad

## Publicering
Förberett för `https://gottjavlakaffe.se/`.
